# Paper audit: what stood between the draft and a submittable paper

Audit of the draft dated 28 October 2026, with the action taken for each limitation and what remains. Positive reviews cannot be guaranteed by any amount of work; the aim is a paper whose claims are measured, whose limits are stated, and whose numbers can be traced.

| # | Limitation found | Action taken | Status |
|---|---|---|---|
| 1 | No figures. | Six figures built from result files by `scripts/make_figures.py`, with an input hash manifest checked by a test. | Closed |
| 2 | Few tables; family and test type results not shown. | Tables for family, test type, baselines, agreement, robustness, verification, tool, specificity, errors, synthetic profiles and the taxonomy, all generated by `scripts/build_paper.py`. | Closed |
| 3 | RQ2 (do binding provisions say how to test) rested on interpretation. | Blind four level specificity coding of all 290 headline rows by two coders, with document level bootstrap intervals. The earlier claim that binding text seldom says how was too strong and is corrected in the paper. | Closed, model coders only |
| 4 | Weak baselines; row level intervals ignore clustering. | Added a frozen sentence embedding baseline with and without a document indicator, and document level cluster intervals. The earlier claim that a keyword rule is the best test type baseline is superseded. | Closed |
| 5 | Related work thin and citations not claim checked. | 33 further works read; 48 cited works checked against their sources (45 supported, 3 partly supported and reworded). 81 works are cited. | Closed for cited works |
| 6 | No research questions or contributions list. | Seven research questions and five contributions stated. | Closed |
| 7 | Tool evaluated only on its own scenarios. | Behaviour on eight synthetic deployment profiles reported, including that the tool names a binding source for only one of eight. | Closed, no user study |
| 8 | Traceability from numbers to files only implicit. | Appendix F traceability map and a test that its paths exist; every number is read from a result file. | Closed |
| 9 | Authorship, anonymity and disclosure. | Author block, anonymous build (`IKHTIBAR_ANON=1`), appendix reporting the use of language models. | Author to confirm affiliation and model disclosure |
